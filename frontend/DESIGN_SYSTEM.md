# DESIGN_SYSTEM.md

> AI 家装产品前端设计系统。每个页面、组件、UI 更新必须遵循此文件。

---

## 1. Project overview

- **产品名称：** AI 家装（暂定名）
- **产品类型：** App / Product UI（移动端优先的 web app）
- **Surface profile：** App / Product UI
- **平台：** web（移动端优先，PC 适配）
- **目标用户：** C 端装修业主，手机操作，不懂设计术语
- **核心设计目标：** 让用户用最少的步骤看到"自己家装修后的样子"，全景图浏览体验是核心差异化

## 2. Brand direction

- **视觉风格：** 专业可信 + 克制的温度感。不是冷冰冰的工具，也不是小红书式的生活化杂乱。
- **调性与语气：** 干净、安静、可信。像一个靠谱的设计师朋友，不推销、不花哨。
- **设计性格：** Corporate-clean（专业可信） + 轻微的 Warm-human（不冰冷）
- **设计概念（Step 2.7 承诺）：**
  > "一个空间预览器——以建筑制图的克制感为底色（大量留白、精确对齐、hairline 分割），但用温暖的木色调和一个明确的'转换'动效（原图→效果图的渐变叠加）传达'你的家正在变化'，而不是冷冰冰的 SaaS 工具感。"

  体现在：
  - 布局：大量留白 + hairline 分割线（建筑制图感）
  - 色彩：暖白底色 + 木色 accent（不是科技蓝/紫）
  - 动效：生成完成时原图→效果图的交叉溶解（"转换"的可视化）
  - 字体：grotesque sans + 数字用 tabular（精确感）

- **对抗性审查结论：** 遮住品牌名，这套设计不会被猜成"贝壳找房"（暖木色 vs 贝壳的蓝白）也不会被猜成"好好住"（克制 vs 内容流堆叠）。弱点：木色 accent 容易做成"家居电商"感，已通过降低饱和度 + 大面积留白来避免。

- **参考来源（web 不可用，基于命名范例推理）：**
  - Linear 的密度和留白节奏 → 信息密度控制
  - Vercel 的精确对齐 → 表单和结果区的网格
  - Airbnb 的图片优先 + 克制色彩 → 结果展示和全景浏览
  - Apple 地图的沉浸式过渡 → 全景图进入动效
  - 竞品 vr.justeasy.cn → 底部场景轮播交互模式

- **UX 文案风格：** 直白、动词优先。不说"开启智能装修之旅"，说"选个风格，看看效果"。空状态有引导，错误状态说原因+怎么办。

## 3. Color system

色彩策略：**Restrained**（克制型）—— 暖白底色为主，木色 accent ≤10%。

| Role | Color | Hex | OKLCH | 用途 |
|---|---|---|---|---|
| 60% — 主色 | 暖白 | `#FAF9F7` | `oklch(0.98 0.003 70)` | 页面背景 |
| 30% — 次色 | 卡片白 | `#FFFFFF` | `oklch(1 0 0)` | 卡片、浮起面 |
| 30% — 次色 | 墨灰 | `#2C2C2E` | `oklch(0.25 0.005 70)` | 主文字 |
| 10% — 强调 | 木色 | `#B8763E` | `oklch(0.58 0.09 65)` | 按钮、链接、选中态、focus ring |
| 辅助 | 次文字 | `#6E6E73` | `oklch(0.52 0.008 70)` | 次要文字、说明 |
| 辅助 | 分割线 | `#E8E6E1` | `oklch(0.92 0.004 70)` | hairline 分割 |
| 辅助 | 成功 | `#3C8C40` | `oklch(0.55 0.12 145)` | 完成状态 |
| 辅助 | 警告 | `#D4791A` | `oklch(0.65 0.12 60)` | 进行中、积分不足 |
| 辅助 | 错误 | `#C0392B` | `oklch(0.50 0.18 25)` | 失败、验证错误 |
| 暗色 | 全景底 | `#0A0A0C` | `oklch(0.08 0.003 70)` | 全景浏览页背景 |

对比度验证：
- `#2C2C2E` on `#FAF9F7`：13.9:1 ✅ AAA
- `#6E6E73` on `#FAF9F7`：5.2:1 ✅ AA
- `#FFFFFF` on `#B8763E`：3.8:1 ✅ AA（大文字/UI）
- `#FAF9F7` on `#0A0A0C`：18.2:1 ✅ AAA

**规则：**
- 背景：暖白 `#FAF9F7`，不用纯白（太冷）
- 文字：主文字墨灰 `#2C2C2E`，不用纯黑（太硬）
- 按钮：主按钮木色底白字，次按钮透明底木色字
- 卡片：纯白 `#FFFFFF` + 轻微暖色阴影，不用边框
- 分割：hairline `#E8E6E1`，仅在表单分割和数据列表行使用
- Focus ring：木色 2px outline，`:focus-visible`
- 分离方式：背景对比 + 阴影，不用边框框住卡片

## 4. Typography system

- **品牌性格：** Corporate-clean + 精确感
- **字体配对：**
  - 标题/正文：**Hanken Grotesk**（grotesque sans，比 Inter 更有性格，圆润中带精确感）
  - 数字：tabular-nums（价格、积分、尺寸等数字场景）
  - 无第二个字体家族
- **为什么选 Hanken Grotesk：** 产品调性是"专业但温暖"。纯中性 sans（Inter）太冷，serif 不适合工具产品。Hanken Grotesk 在 grotesque 的精确骨架上带轻微的温度感，和暖白+木色的色彩系统呼应。

- **Type scale（命名步骤 + 精确值）：**

| Step | Mobile | Desktop | 用途 |
|---|---|---|---|
| display | 28px / 600 / 1.2 | 32px / 600 / 1.2 | 登录页标题 |
| h1 | 22px / 600 / 1.3 | 24px / 600 / 1.3 | 页面标题 |
| h2 | 18px / 600 / 1.4 | 20px / 600 / 1.4 | 区块标题 |
| h3 | 16px / 600 / 1.4 | 16px / 600 / 1.4 | 小节标题 |
| body-lg | 16px / 400 / 1.5 | 16px / 400 / 1.5 | 正文 |
| body | 15px / 400 / 1.5 | 15px / 400 / 1.5 | 正文（紧凑） |
| body-sm | 14px / 400 / 1.5 | 14px / 400 / 1.5 | 辅助文字 |
| caption | 13px / 400 / 1.4 | 13px / 400 / 1.4 | 时间戳、元信息 |
| button | 15px / 500 / 1.2 | 15px / 500 / 1.2 | 按钮文字 |

- **正文最小：** 16px（body-lg）/ 15px（body），从不低于 15px
- **行高：** 1.5（正文），1.2-1.4（标题）
- **行宽：** 60-75ch（文字密集区），移动端全宽
- **响应式：** clamp() 在 display/h1 上做流体缩放

## 5. Layout system

- **容器宽度：** 移动端 100% - 32px padding（左右各 16px），最大 480px 内容区居中
- **区块间距：** 24px（移动端），32px（桌面）
- **网格：** 移动端单列，桌面两列（生成参数 / 预览结果）
- **页面结构：** 底部 Tabbar 导航（生成 / 历史），全屏页（全景浏览）无导航
- **全景页：** 全屏 fixed，顶部浮层（返回 + 标题 + 分享），底部场景轮播
- **移动优先行为：** 所有页面按 375px 宽度设计，向上适配
- **断点：** mobile 375px / tablet 768px / desktop 1280px+
- **对齐：** 左对齐为主，标题居中仅用于登录页和空状态

## 6. Component system

- **组件库：** Vant 4（移动端组件库），深度 re-theme 到上述 token，**不用默认蓝色**
- **按钮：**
  - 主按钮：木色 `#B8763E` 底，白字，圆角 8px，高 44px
  - 次按钮：透明底，木色字 + 木色边框，圆角 8px
  - 文字按钮：无底无边，木色字
  - 状态：hover → 加深 10%，active → scale(0.97)，disabled → opacity 0.4
  - loading 态：文字替换为"生成中..."+ spinner，按钮不可再点
- **卡片：** 白底 `#FFFFFF`，圆角 12px，阴影 `0 1px 3px rgba(0,0,0,0.04)`，无边框
- **标签/徽章：** pill 形，12px 字号，padding 2px 8px，语义色
- **导航栏：** 顶部 NavBar（白底 + hairline 底边），底部 Tabbar（2 tab：生成 / 历史）
- **表单：** Vant Cell Group 风格，label 在上方，输入框白底，focus 时木色底线
- **输入框：** 44px 高，圆角 8px，placeholder `#A8A8AD`
- **空状态：** 插图 + 一句话说明 + 主 CTA
- **加载态：** skeleton 占位（不用全屏 spinner）
- **错误态：** 文字说明 + 重试按钮

## 7. Card & section style

- **样式：** 无边框 + 轻阴影 + 圆角
- **圆角：** 卡片 12px，按钮 8px，标签 pill，图片 8px
- **阴影：** `0 1px 3px rgba(0,0,0,0.04)` — 几乎不可见但能区分层次
- **渐变：** 不使用
- **毛玻璃：** 仅全景页顶部浮层（`backdrop-filter: blur(12px)` + `rgba(0,0,0,0.4)`）
- **规则：** 不嵌套卡片（卡片内不再放卡片）

## 8. Icon system

- **图标库：** Vant 内置图标（已和组件库统一），不自引第二个图标库
- **尺寸：** 20px（导航），16px（行内），24px（空状态）
- **颜色：** 继承 currentColor
- **规则：** 图标+文字成对出现，不用 emoji 作结构图标

## 9. Image & asset rules

- **Logo：** 文字 wordmark（待设计），暂用文字标题
- **用户上传图片：** 原图按比例显示，最大高度 200px 预览，圆角 8px
- **生成结果图：** 全宽展示，圆角 12px，加载用 skeleton
- **全景图：** 全屏黑色底，Photo Sphere Viewer WebGL 渲染
- **缩略图：** 64×64px，圆角 6px，object-fit cover
- **裁切：** 统一 4:3 或 16:9，不混用
- **格式：** JPG for photos（不存 PNG，前面分析过 PNG 浪费空间且不清晰）

## 10. Animation & interaction system

- **动画库：** CSS-only（transform + opacity + transition），不引 GSAP
- **过渡时长：** 150ms hover，200ms 页面切换，300ms 全景进入
- **缓动：** `ease-out` 进入，`ease-in` 退出
- **按钮交互：** hover 加深，active scale(0.97)，focus-visible 木色 ring
- **生成完成动效：** 原图→效果图交叉溶解 300ms（产品核心"转换"体验）
- **全景进入：** 从缩略图位置放大到全屏 300ms ease-out
- **场景切换：** 底部轮播横滑，当前场景高亮，Photo Sphere Viewer `setPanorama()` 平滑过渡
- **异步反馈：** 提交→button loading，等待→进度文字+骨架，完成→toast+展示结果
- **Toast：** 顶部居中，2s 自动消失，成功绿色+✓，错误红色+⚠
- **表单验证：** blur 时校验，错误在字段下方红字
- **空/加载/错误三态：** 每个数据视图都有
- **Reduced motion：** 全部动画降级为 instant

## 11. Accessibility rules

- **对比度：** 已在 §3 计算验证，全部 ≥ AA
- **Focus：** `:focus-visible` 木色 2px outline，不移除
- **键盘：** 全部可 tab 操作，tab 顺序 = 视觉顺序
- **语义：** 语义化 HTML + ARIA landmarks
- **表单：** `<label>` 关联，错误 `aria-describedby` + `role="alert"`
- **触摸目标：** ≥ 44×44px
- **状态：** 不只靠颜色区分（配图标/文字）

## 12. Anti-AI-slop rules

- **批准的调色板（唯一允许的颜色）：**
  `#FAF9F7` `#FFFFFF` `#2C2C2E` `#B8763E` `#6E6E73` `#E8E6E1` `#3C8C40` `#D4791A` `#C0392B` `#0A0A0C`
- **是否使用纯 `#000`/`#fff`？** `#FFFFFF` 仅用于卡片浮起面（概念允许），不用于文字（用 `#2C2C2E`）或页面底（用 `#FAF9F7`）
- **概念测试结论：** 遮住品牌名——暖白+木色不是家装行业默认配色（行业默认是蓝白或米黄），建筑制图式留白+hairline 不是 AI SaaS 默认。弱点：木色 accent 需控制饱和度避免"电商"感。
- **项目特例：** 全景页使用 `#0A0A0C` 接近纯黑——因为全景浏览需要暗色底沉浸感，这是刻意选择。
